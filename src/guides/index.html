Learn MCP by building one

The Model Context Protocol is a small, boring protocol wearing a big name. It is stateless JSON-RPC 2.0 over a pipe, plus an agreed vocabulary for three things a model might want: tools it can call, resources it can read, and prompts a user can invoke.

These guides target revision 2026-07-28. That revision removed the initialize handshake and protocol-level sessions: every request now carries its own version and capabilities in _meta, and any server instance can answer any request. Anything written for 2025-11-25 or earlier describes a handshake that no longer exists.

Why it exists

Before MCP, every AI app wrote its own integration for every tool. N apps × M tools = N×M adapters. MCP makes it N+M: each app speaks MCP once, each tool speaks MCP once.

The whole value proposition, drawn twice.

What you need

Bun (already in this repo), an editor, and about an hour. The build chapter uses zero dependencies on purpose — the official SDKs are excellent, but you learn the protocol faster when you can see every byte, and nothing hides which revision you are actually speaking.
