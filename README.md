# Web Playground

A Tauri 2 desktop app with SolidJS, Vite Plus, and Tailwind CSS.

```sh
bun install
bun run desktop
```

`bun run dev` starts the frontend in a browser. `bun run desktop:build` builds the desktop app. Tauri requires Rust and the platform prerequisites described in the [Tauri setup guide](https://v2.tauri.app/start/prerequisites/).
